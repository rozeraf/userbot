# Roadmap

Активные задачи расположены по приоритету. Статусы: `planned`, `research`, `in progress`, `blocked`. При начале работы задача получает владельца/ветку и проверяемые критерии готовности; завершённая работа переносится в «Готово».

## P1 · Userbot Workspace — planned

Цель: отдельный приватный supergroup-форум как безопасный интерфейс юзербота вместо «Избранного».

- [ ] Создать приватную supergroup с forum mode.
- [ ] Идемпотентно создавать топики `Chat`, `Saved`, `Media`, `System`.
- [ ] Хранить workspace `chatId` и topic ID, не полагаться на названия.
- [ ] Разрешить в `Chat` обычное общение без `!`-команд.
- [ ] Использовать `Saved` и `Media` как тихие хранилища.
- [ ] Отправлять логи, ошибки и служебные уведомления в `System`.
- [ ] Вне workspace реагировать только на явно вызванные `!commands`.
- [ ] Вынести управление и routing по topic ID в `core/workspace`.
- [ ] Добавить recovery-тесты для повторного запуска и отсутствующих топиков.

Готово, когда повторная инициализация не создаёт дубликаты, удалённый базовый топик восстанавливается, а маршрутизация проверена тестами.

## P1 · Summary последних сообщений — planned

- [ ] Поддержать `!summarize N` для последних `N` сообщений текущего чата или топика.
- [ ] Ввести верхнюю границу `N`, лимит графем и понятную оценку обрезанного контекста.
- [ ] Исключить служебные команды из анализируемого контекста.
- [ ] Добавить parser и prompt tests.

## P2 · Семантический поиск — research

- [ ] Определить локальную модель embeddings и способ обновления индекса.
- [ ] Добавить `.find <описание>` по доступной истории.
- [ ] Возвращать чат, дату, автора и ссылку на исходное сообщение.
- [ ] Отдельно спроектировать индексирование подписей и медиа.
- [ ] Описать retention, reindex и удаление приватных данных.

## P2 · Память о людях — research

- [ ] Спроектировать `.person @username`: первое/последнее общение и общие чаты.
- [ ] Выделять темы, обещания и упомянутые даты только с указанием источников.
- [ ] Добавить ручное исправление, удаление и отключение сбора.
- [ ] До реализации зафиксировать модель приватности и сроки хранения.

## P2 · Проверка утверждений — planned after search

- [ ] Добавить `.searchclaim <утверждение>` поверх семантического поиска.
- [ ] Показывать подтверждающие и опровергающие цитаты со ссылками.
- [ ] Отделять найденные факты от интерпретации LLM.

## P3 · Автоисправление сообщений — research

- [ ] Проверять только собственные сообщения после небольшой задержки.
- [ ] Начать с режима подтверждения и allowlist чатов.
- [ ] Редактировать только при высокой уверенности без изменения смысла и стиля.
- [ ] Добавить kill switch, rate limit и журнал правок.

## Технический долг

- [ ] Добавить GC для давно неиспользуемых `messages/<chatId>` rows в `tui_revisions`; global `messages/""` epoch должен инвалидировать выбранный чат после GC.
- [ ] Добавить интеграционные тесты reconnect/backpressure для TUI UDS.
- [ ] Сделать systemd unit устанавливаемым без захардкоженного пути репозитория.

## Готово

- [x] Native `!remind`: scheduled message в «Избранном», диапазон 10 секунд–365 дней, единицы `s/с`, `m/м`, `h/ч`, `d/д`.
- [x] Durable command execution и восстановление прерванных команд.
- [x] Scoped TUI revisions, coalesced UDS wakeups и `data_version` watchdog.
